## Installation

```bash
# ensure you're in the folder you wanna put this in
$ pwd 
# outputs something like this:
/Users/trenton/chatbot3

# Clone the repository
$ git clone https://github.com/coxtrent/chatHGPstartercode.git

# Change directory
$ cd chat

# Install dependencies
$ npm install
```
Alternatively, use GitHub Desktop
- Press green Code button
- Select HTTPS
- Copy URL
- Open GitHub Desktop and look for "Clone Repository"
- Paste the URL and hit clone
- Click "Open in Visual Studio Code"

## Usage

DO NOT use the "Go Live" button to run this project.

```bash
# start your server 
npm start
```
